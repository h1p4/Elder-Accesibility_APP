
📌 Descripción

Este proyecto consiste en el desarrollo de una aplicación Android orientada a facilitar la interacción con el dispositivo móvil, especialmente para usuarios que requieren una experiencia más sencilla, intuitiva y controlada.

La aplicación funciona como una pantalla principal personalizada (launcher simplificado), proporcionando acceso rápido a las acciones más utilizadas del teléfono, como llamadas directas a contactos frecuentes, evitando distracciones y reduciendo la complejidad del sistema operativo.

Además, la aplicación se inicia automáticamente al encender el dispositivo y limita la salida accidental de la aplicación para mantener una experiencia estable y segura.

🎯 Objetivos del Proyecto
Simplificar el uso cotidiano del smartphone.
Mejorar la accesibilidad y usabilidad.
Reducir errores de navegación accidental.
Facilitar acceso rápido a funciones esenciales.
Crear una interfaz enfocada en personas con poca experiencia tecnológica o necesidades especiales.

🧠 Características Técnicas

🔹 Auto Start

La aplicación detecta el encendido del dispositivo e inicia automáticamente la interfaz principal.

🔹 Modo Kiosk / Restricción de Salida

Se implementaron mecanismos para minimizar la salida involuntaria de la aplicación y mantener al usuario dentro del entorno simplificado.

🔹 Gestión de Contactos

Acceso rápido mediante botones personalizados para llamadas directas a contactos configurados.
